# Expo Uruguay 26 · Mapa interactivo (DEMO)

App kiosco + celular para la ExpoCannabis Uruguay 2026 (sáb 5 y dom 6 de diciembre, Centro de Eventos LATU, Montevideo). Propuesta de Kionda. Todos los datos son DEMO.

Publicada con GitHub Pages: https://kionda043-alt.github.io/expo-uruguay-26/

- `index.html`: la app.
- `assets/img`, `assets/video`: imágenes y videos.
- `assets/fonts`, `assets/js`: tipografías y generador de QR, locales.
- `manifest.webmanifest`, `icons/`: instalación en el celular.
- `sw.js`: guarda todo para que funcione sin internet.
